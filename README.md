# UAC System Capacity & Pipeline Analytics 🛡️

An interactive, Python-based dashboard designed to analyze the federal care pipeline for Unaccompanied Alien Children (UAC). This project tracks operational scale, capacity bottlenecks, and pipeline pressure across CBP and HHS facilities.

## 📊 Core Features
* **Automated Data Validation:** Actively identifies and flags logical reporting anomalies (e.g., daily transfers out exceeding total reported custody) to ensure data integrity.
* **Theme-Adaptive UI:** Custom CSS engineered to perfectly adapt to both Light and Dark operating system modes while maintaining executive styling.
* **Dynamic KPIs & Routing:** Tracks Peak System Load, 7-Day Rolling Averages, and Acute Pressure Events using interactive Plotly visualizations.

## 🛠️ Technology Stack
* **Language:** Python
* **Framework:** Streamlit
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly (Express & Graph Objects)
